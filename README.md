# Оно тебе надо

Учебная страница аукциона вещей, в которые никто не верил. Проект выполнен в рамках курса «Ассоциированные программы: Фронтенд-разработка» Яндекс Практикума.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Структура

- `index.html` — разметка страницы;
- `styles/global.css` — базовые стили;
- `styles/style.css` — стили блоков страницы;
- `fonts/fonts.css` и файлы шрифтов — локальные шрифты;
- `images/` — изображения и иконки.

## Проверка

Откройте страницу в Chrome или Firefox и сравните её с макетом проекта. Проверьте ссылки, отсутствие горизонтальной прокрутки и отображение локальных шрифтов и изображений.
